> **Aetheria Canvas**

_Interactive Generative Art Playground & Mathematical Physics Visualizer_



**✦ Key Features & Capabilities**

1. Multi-Engine Generative Mechanics

Simplex Flow Fields: Simulates organic fluid dynamics, vector fields, and atmospheric smoke trails using custom 2D Simplex Noise algorithms.

Orbital Gravity Attractors: Turns cursor or touch input into custom gravitational nodes, causing thousands of particles to orbit, swirl, and collide in deep space dynamics.

Sacred Harmonic Lissajous Curves: Generates symmetrical, mathematical geometric figures based on harmonic frequency ratios and orbital oscillations.

2. High-Performance Rendering Architecture

60 FPS Hardware Acceleration: Driven by a native HTML5 Canvas 2D engine with delta-smoothed animation loops.

High-DPI / Retina Crispness: Dynamic pixel-density scaling (window.devicePixelRatio) ensures ultra-sharp lines without blurriness on high-resolution displays.

Zero External Dependencies: Built entirely in pure vanilla JavaScript (ES6+ OOP), making execution instantaneous, lightweight, and responsive.

3. Deep Customization & Visual Controls

Physics Tuning: Dynamically scale particle density from 200 up to 10,000 active nodes, alter velocity multipliers, change field frequencies, and adjust trail persistence (decay rate).

Curated Color Spectrum Palettes: Switch effortlessly between vibrant spectrums including Cyberpunk Neon, Aurora Borealis, Celestial Cosmic, Solar Plasma, and Monochrome Silver.

Advanced Render Effects: Toggle additive glow blending for neon luminescence and proximity mesh lines to link nearby particles into constellation-like structures.

4. Ultra-Lightweight OLED UI

Non-Intrusive Drawer Interface: Sleek, tabbed controls (Physics, Visuals, Presets) keep the interface out of the way of the art.

Live Telemetry Overlay: Real-time performance metrics tracking active particle counts and render frame rates (FPS).

Presets & Local Storage: Save custom parameter states or choose from curated quick presets (Quantum, Hyperspace, Nebula, Harmonic).

5. Utility & Export Suite

High-Res PNG Capture: Instantly export canvas state snapshots at full dynamic screen resolution with a single button press or keyboard shortcut (S).

**Keyboard Hotkeys:**

Space — Pause / Resume animation

R — Reset canvas state

S — Export PNG screenshot

H — Toggle HUD settings panel visibility

**✦ Technical Specifications**

Technology Stack: HTML5, CSS3 (Tailwind CSS utilities), Vanilla JavaScript (ES6+ Class Architecture)

Optimization Level: Zero GPU backdrop blur filters to guarantee smooth performance on low-end laptops and mobile devices.

Compatibility: Universal cross-device compatibility (Desktop, Tablet, Mobile) with full multi-touch support.
